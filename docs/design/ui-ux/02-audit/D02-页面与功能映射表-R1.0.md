## 4. 导航与外壳差距（供 Phase 1 使用）

- 当前：`NAV` 扁平 7 项（`App.tsx:17-26`）+ 底部设置；侧栏 208px（`index.css:330`）。
- 目标：工作空间（5-6 项）/ AI 工作空间（3 项）/ 系统管理（2 项，可含子项）三组；220–240px。
- 必须保留：现有 10 条路由与认证门控；不新增业务页面；不删除入口。
- 可增量实现：分组标题与 `<nav aria-label>`、折叠 toggle、Shell 级 Page Header + 面包屑、Toast 容器、ErrorBoundary、`Route path="*"` 兜底。

## 5. 优先级建议（Phase 1）

| 优先级 | 动作 | 风险 | 验证 |
