# ADR-BROWSER-005：逐条用户确认发送

- **状态：** Proposed（原文：产品决策已确认；与 ADR-0003 D-6/D-7 一致）
- **来源：** 《ICA Browser Subsystem Architecture R1.0》§8（B0-06 冻结，2026-11-20）
- **关联：** B7 卡（发送实施）、`browser_approvals` 表（B0-08 对账）

---

**决策：** 浏览器可以执行单条消息发送，但必须由用户逐条确认。

关键约束：

- 每条消息一个审批。
- 审批绑定候选人、账号、会话和消息 Hash。
- 只能执行一次。
- 页面或消息变化使审批失效。
- 不提供 Agent 自主批量发送。
- 不确定状态不得自动重试。
